## Minimap editor hotfix and error recovery

- **Minimap updates after Apply**: the drawing is synchronised with the updated map before rendering, avoiding a frame that mixes the previous design with the new track data. Missing colours fall back to grey instead of causing a rendering error.
- **Errors inside dialogs** now show a message and a **Close** button instead of taking down the whole editor interface.
- **Errors outside dialogs** show an error message and a **Reload** button instead of leaving an empty window. Reload restarts the interface; unsaved changes are lost.

The reported black screen when saving minimap edits could not be reliably reproduced. These changes address a stale drawing state and improve error recovery; they are not confirmation that every cause of that black screen has been resolved.

## Track lists

- Fixed overlapping rows in **All tracks** when **Video previews** is off. Rows keep their full height and the list scrolls correctly.

## Create a new track

### Starting grid and layout checks

- **Move start to a straight part** finds the nearest suitable position for the twelve-kart starting grid, adding a point along an existing section if needed, while preserving the track's shape.
- The starting-grid warning explains why placing the start on a bend can leave karts off the road. Its repair action is available beside the issue and near **Generate track**.
- **Set start here** moves shortcut positions with the lap, so their ends stay attached to the same parts of the road. Shortcuts crossed by the new start line remain in the editable list with an explanation instead of being silently deleted.
- Automatic boost placement avoids stretches leading directly into a tight bend, preventing a boost panel from being placed into the sharp turn.

### Multiple shortcuts

- **No fixed shortcut count imposed by the editor**: draw shortcuts one after another, including overlapping or nested shortcuts and shortcuts that share an end.
- Checkpoints, enemy routes and item routes are connected across the main road and each shortcut. Short sections receive at least one point so their groups are not empty.
- Point spacing adjusts across the main road and shortcuts to stay within the game's 255-checkpoint and route-point budgets where the layout permits it. Multiple-shortcut generation and KMP export/reload have been checked with **30 shortcuts on one track**.
- A shortcut uses the shorter stretch between its ends, regardless of the order in which they were clicked. One that skips the start line is reported individually and no longer prevents other valid shortcuts from being generated.
- **Move the start out of the shortcut** looks for a position outside the shortcuts where the starting grid also fits.
- Warnings identify the affected shortcut (**S1**, **S2**, etc.), explain why it was left out, and appear in both **Race** and **Check**. Excluded shortcuts have red labels on the drawing.

The game's limits still apply: every lap must cross the start line, and a junction can have at most six incoming or outgoing route connections. Invalid shortcuts are reported rather than silently included.

### Shortcut height and walls

- Each shortcut has its own **Height**, **Follow road** and remove controls in **Race**, with matching numbered labels on the drawing.
- Height raises or lowers the middle of a shortcut, with smooth ramps at both ends. Shortcuts too short to reach the selected height with climbable ramps are left out with an explanation.
- Raised shortcuts receive support pillars; the visual ground is placed below lowered shortcuts as well as the main road.
- Improved wall joins between shortcuts and the main road to close gaps at entrances and exits. Walls open where roads meet or cross at the same height, including between shortcuts, while elevated crossings retain their walls.

### Drawing and dialog controls

- **Shortcut** is available in the drawing toolbar and opens **Race** automatically. **Add another shortcut** returns to the tool, and finishing a shortcut leaves it ready to draw the next one.
- The list distinguishes shortcuts drawn from those included in the generated track. **Esc** cancels an unfinished shortcut, and changing tools or stepping through history clears the unfinished drawing.
- **Ctrl+Z / Ctrl+Y** undo and redo shortcut additions, removals and height changes.
- The footer explains how many problems block **Generate track**. **Show** centres the drawing on a reported problem.
- Shape choices distinguish **Start from a complete track** from **Or only a shape**, with clearer guidance about the starting straight.
- Using the mouse wheel over the **2D drawing** zooms the map without moving the surrounding column's scrollbar.
