## Create a new track

**New track** now includes textured roads, editable heights and a live **3D** preview before generating the SZS.

- **Choose a track style**, then draw its layout or start from a preset. Asphalt, rally, desert, snow and castle styles set the surfaces and textures; individual surfaces can use another preset or your own PNG, JPEG or WebP image, with adjustable repeat.
- **Height** above the drawing raises and lowers individual road points. Drag a point vertically, hold **Shift** for finer control, use the arrow buttons, or enter an exact height. The controls stay available while editing road settings and textures; **Undo/Redo** restores each change.
- **2D / 3D** switches between the drawing and an interactive preview of the generated road, walls, bridge decks and supports. Drag to orbit, right-drag to pan and use the wheel to zoom. Select a point in 3D and change its height without resetting the camera.
- **Boost panels** use the game's original animated material when the game resources are available. Place them on the drawing, drag them to another position or remove them individually; their animation is kept in the generated track.
- **More reliable curves and generation**: improves uneven hand-drawn corners, texture sampling and elevated road geometry, and fixes the converter's recursion error on long connected roads.

## Game text and native colours

- **Text colour** applies the game's native BMG colours to a selection or the whole message. **Default (layout)** restores the screen's original colours; icons and font-size codes are retained.
- **Ctrl+X** cuts selected text without splitting a game code. **Ctrl+Z**, **Ctrl+Y** and **Ctrl+Shift+Z** undo and redo text, colours, icons and font-size changes, including edits across messages. Colour swatches no longer show tooltips.
- **More accurate game screens**: improves message-to-screen bindings, menu buttons, engine-class selection, multi-line windows, controller prompts and battle cup icons. Previews use the loaded game's layouts, textures and fonts, including modified resources.
- **Honest fallback previews and limits**: known messages use their layout's actual text capacity. Messages without a verified screen use a clearly identified generic preview, with no invented character limit.

## Collision editing and duplication

- Choosing **Collision** in the viewport also opens the **Collision** sidebar on **Show**. Selection, transforms and triangle-editing tools are now together in **Show**; **Paint** remains separate.
- The redesigned panel groups selection, vertex editing, triangle creation, visibility and file actions more clearly.
- Copying or duplicating an object or track-model part asks whether its collision should be included. The choice can be remembered for that object/model, and the resulting edit supports **Undo/Redo**.

## Model import fixes

- **Palette and PAT0 support**: handles indexed textures and animated palette changes by preserving the palette colours as texture variants and transferring the pattern animation, rather than rejecting palette animation outright.
- Fixes additional ABMatt import failures, including valid models rejected with **“ABMatt changed existing texture block”**, and preserves existing texture resources when adding a model part.
- Improves material, texture and weighted-model handling. Missing palette resources now produce an error identifying the required palette and the palettes present in the BRRES.

## Smoother previews and a smaller download

- **Characters and models** no longer flashes empty frames while resizing its panels.
- Opening a track from **Cups and tracks** shows loading feedback until its separate 3D editor is ready, and blocks further clicks during loading.
- Removes the thin bright seams around track-video backgrounds in cup rows and track lists, including at Windows display scaling.
- **Smaller Windows EXE**: reduces the download from about **147 MB to 79 MB**, using lossless compression. The runtime, ABMatt and Wiimm tools remain included; no features or texture quality are removed.

**Windows x64:** download `MKWiiAdvancedEditor.exe`. The accompanying `.sha256` file verifies the download and is also used by the in-app updater.
