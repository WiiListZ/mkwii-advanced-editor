## Game text

- **Text limits come from the game's layout files**: the editor shows a used/maximum counter and rejects typing or pasting beyond the text box's capacity. Original layouts allow 32 characters for course-selection track names, 40 for character and vehicle names, and 20 for cup names.
- Names and button labels stay on **one line**. Game codes count toward the available space; insertion and font-size changes respect the same limit.
- Buttons, the bottom instruction bar and generic message windows use their own layout capacities too: the original Back button holds 20, standard menu and pause buttons 32, the bottom instruction bar 100, menu message windows 350 and race messages 200. Multiline messages retain their line breaks.
- The preview respects the text box's capacity too. When a message has no known layout or the game files are unavailable, the editor does not invent a limit.

## Updates

- **Download update** downloads and verifies the executable without closing or restarting the editor.
- When the download finishes, **Restart & install update** lets you choose when to install it. Unsaved track changes are saved before restarting.
- **Later** keeps the downloaded update ready; the restart button remains available in the update banner and About.

## Cups and tracks

**Tools › Cups and tracks…** makes choosing cups, replacing tracks and editing their music and previews easier.

- **Cups of** is now a dropdown: choose the game's cups or an opened mod from one place.
- **Rename…** has its own button beside **Replace**.
- **Replace › Create a new track…** opens the track generator, saves the new archive and assigns it to that cup position. Cancelling keeps the previous track. Add the track and sky models before applying if the checks report them missing.
- **Music** sits at the bottom left of each track row, with more room for its name. The tracks that originally use that music are shown in parentheses, and the selection arrow stays immediately after the text.
- The **chosen music stays visible after Apply**, including after reopening the editor. Restoring a backup restores the displayed music choice too.
- The **THP preview** appears under the music. Click its filename to open the preview video editor with that track's part already selected.
  - It follows the track when **Preview videos follow the tracks** is on; otherwise it stays with the cup position.
  - Its tooltip appears below the control and lets the pointer through, so it cannot block the music above it.
- Track-row buttons use the editor's **custom tooltips**, with explanations for moving, swapping, replacing, renaming and resetting tracks. Tooltips close when a menu or another window opens.

### New cups and Riivolution

- **New cup** guides you through creating a **Riivolution cup pack**, with your cups after the game's original eight.
- Choose a pack name and a destination folder. The editor prepares the pack, its **Riivolution XML** and instructions, without asking which platform you play on.
- After applying, open the pack's XML or the Riivolution mod editor directly from Cups and tracks.
- Cancelling or discarding a new pack keeps the original game files unchanged.

### Backups

- Apply and video-save confirmations always include **Make a backup first?**. Choose whether to create a backup for that operation.
- Turning it off writes the change without a snapshot or `.bak` files, even if backups are enabled in Settings.
- The **Back** button in the backup sections returns to Cups and tracks or Preview videos without closing the window.

## Remove collision from a model or object

Select a track model part or a placed object, then choose **Remove all collision…** beside **Generate collision…** in the Inspector, or in the context menu.

- Removes the course collision matching the selected model parts or objects, keeping their models in the track.
- A **confirmation window** shows how many collision triangles will be removed.
- **Cancel** leaves the collision unchanged. **Ctrl+Z** restores it, and **Ctrl+Y** reapplies the removal.
- Save the SZS to keep the change; the removed collision stays removed after reopening the track.

## Object documentation

- **Sync** downloads the latest default object documentation whenever you need it.
- **Last sync** shows the date and time of the last successful sync, including automatic updates, and is remembered between sessions.
- While syncing, the button shows its progress. If GitHub cannot be reached, the last successful documentation and sync time are kept.
