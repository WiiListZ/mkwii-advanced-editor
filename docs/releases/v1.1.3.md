## Model files in depth

- **Animations, keyframe by keyframe** (*Tools › Animations of this track…*, **Edit keyframes…** on an animation, **Edit all animations…** in Characters and models): bones (CHR0), texture movement (SRT0), colours (CLR0), texture swaps (PAT0) and visibility (VIS0). Each channel can be not animated, a fixed value or keyframes with frame, value and tangent, shown as a curve, with **Smooth tangents**. Animations can be created and deleted, and bones or materials added. All 686 animations of the game's tracks and `Common.szs` were written again this way and play the same at every frame.
- **TEV stages** in *Materials*: textures, coordinates, light channel, colour and alpha inputs, operation, bias, scale, clamp, output, konst selections and swap tables, with stages added (up to 16) or removed. Every material of the game is written back byte for byte.
- **Vertices and UVs…** for a track model part or a polygon in Characters and models: texture coordinates over the texture, to drag, type, flip or select by box, and positions in a table.
- **Format and size…** in the texture painter: any direct format (I4, I8, IA4, IA8, RGB565, RGB5A3, RGBA32, CMPR), any size from 4 to 1024 pixels, any number of mipmaps, from the texture or from an image of any size.
- **Scene lights and cameras (SCN0)**: lights, ambient lights, fog and cameras stored in a model file.
- **Sound properties** in *Sounds and music*: volume, priority, player, pan and Wii Remote filter of a sound effect in `revo_kart.brsar`.
- Not included: vertex weights and draw order, shape animation (SHP0) keyframes, adding new sounds to the sound archive (the game plays sounds by number, so a new one would never be used) and effect animation curves (their format is not documented).

## Fixes in reading the game's files

- Textures stored as TEX0 version 2 (118 of them in the game's object models) were read with the wrong size and format. They now show and edit correctly.
- Bone and texture animations with keyframes before frame 0 (stored as I6) placed those keys at frame 2047, so some of the game's moving objects (trees, boats, Mii crowds and mission rings among them) did not move correctly in the 3D view.

## Track check: crashes told apart, no errors on the game's own tracks

- The check now runs on all 51 of the game's own tracks and arenas without a single error. Battle arenas and the demo and mission scenes no longer get errors for missing checkpoints or item routes. Route-searching cameras (type 2) without a route, fixed cameras linking a route they do not use, and one-point routes are no longer errors either: the game's own tracks have them.
- Issues are now listed in sections in **Check** and in the save window: **Crashes or freezes the game** first, then errors that break races, warnings and notes. Problems that crash the game have their own icon, and the save window only says the track will crash when one of them is there.
- Arenas no longer show hundreds of warnings about their enemy route links, which are a network rather than a lap. Key checkpoint numbers that skip a value are now a note, as on some of the game's tracks.

## Saving

- The save window has **Don't show this again until the editor is closed**. With it, saving no longer stops for errors or warnings for the rest of the session.

## Cameras

- Fixed the editor's 3D view keeping a camera's field of view after leaving the cameras. The normal view returns when you leave the **Cameras** tab. After **Go to camera** elsewhere, it returns as soon as you move the view yourself.

## Sounds and music

- **Sound effects and voices** now lists every sound in `revo_kart.brsar`, not only the first 400. The list stays fast, however many there are.

## Discord activity

- More statuses: the open tool (effects, minimap, music and sounds, game text, cups, preview videos, textures, sculpting, a new track…), **Listening to** the music or sound being played, watching the intro or a ghost replay, painting collision and the 2D map. They also show from the home screen.

## Minimap (beta)

- The **In game** panel shows the finish line as a checkered bar across the road, as the game draws it over the map. It is drawn by the editor, not taken from the game's files, so its exact look may differ a little.

## Validation status

The new editors were checked against every file of the game: all animations, all TEV shaders and all SCN0 scenes are written back unchanged. The automated tests pass, including new ones for the game's own track cases, the crash marking and the Discord statuses. The check was run on all 51 original tracks of the game with no errors. The field of view fix, the save window option, the Discord statuses and the minimap finish line were checked in the editor. Sound properties were changed and read back on the game's own `revo_kart.brsar`; the full sound list was not opened in the window with it. These changes have not been verified on a Wii or in Dolphin.
